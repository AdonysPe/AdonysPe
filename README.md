## About me

- **Building [Korte](https://portfolio-nu-seven-62.vercel.app/)**, a booking & scheduling SaaS for barbershops on multi-tenant PostgreSQL.
- Full-stack TypeScript: App Router, server actions, Prisma / Drizzle, auth and transactional email.
- I care about motion: GSAP, Framer Motion, Three.js scenes and Remotion videos.
- Background in Java & Android; now shipping web products end to end on Vercel.
